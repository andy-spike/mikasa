# Two-phase generation with a Tailor agent

Generating a whole course in one shot produces bad curricula with no checkpoint: the user pays for 40 lessons before discovering the outline is wrong. We generate the Outline first (Default model), let the user shape it with a manual editor and a chat-based Tailor, then generate the Lessons (Strong model, one Exercise per Lesson stepping toward the Goal). After generation the course stays mutable: the Tailor proposes change plans the user approves, with per-change undo that restores completion state. The Tailor runs on the Default model with an opt-in switch to the Strong model for large changes.

**Amended 31 AUG 2026.** Lessons are generated as one cohesive block on approval, not on demand as the learner reaches them. Per-Lesson generation made each Lesson a separate call with only the Outline for context, which cost coherence across a Course — a later Lesson could not build on the exact wording of an earlier one, and callbacks between Modules had to be guessed. One pass buys that coherence and makes the state model smaller: a Course is written or it is not, and no Lesson inside a generated Course is missing. The Outline checkpoint is unchanged and is now the only place generation pauses.
