# Surface brief: course workspace

Scope: the authenticated course workspace (route to live under `app/courses/[courseId]`), visitor mode **Operate**. The learner works through one Course: contents (Modules → Lessons), the current Lesson, Tutor, Tailor.

Audience: general self-learners in evening deep-work sessions at a desk.

Job: see where they are in the course, read the current Lesson, mark the Exercise done, ask the Tutor, reshape via the Tailor.

Action/proof: the contents page is the working surface; progress state (done / ghost / next) must read without color alone.

Direction: **The Reading Room** (direction roll d3f00ad5, round 2, user-locked). Course as an open volume on a night desk: bottle-green room, vellum page, brass marker, dated ink stamps, pencil marginalia for the Tutor, re-catalogued pages for Tailor changes.

Memorable moment: the due-stamp settling when an Exercise is marked done.

Constraints from the raises:
- Ghost entries: not-yet-generated Lessons are ruled empty slots, deliberately drawn.
- Everything snaps to one invisible module grid (Tailor rearrangements re-flow cleanly).
- Inactive furniture de-tensions to ash gray; nothing disappears.
- Tone via ink density, not color badges.
- Posting-red-style accent rationing: the brass marker means exactly one thing (the next entry).

Unresolved: none blocking. First build is frontend-only; generation, Tutor, and Tailor run as designed states on authored demo content.
